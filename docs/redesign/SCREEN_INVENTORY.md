- `file:line` references are 1-based lines in the current worktree.
- "Route" = a `GoRoute` path in `lib/app/router.dart`. "Push" = imperative
  `Navigator.push` / `context.push` call site.
- API calls are listed as `repo/provider → METHOD /path` where the endpoint is
  visible in code; "unverified" where the endpoint could not be confirmed.
- State handling columns: **L**oading, **E**mpty, **Err**or, **R**etry —
